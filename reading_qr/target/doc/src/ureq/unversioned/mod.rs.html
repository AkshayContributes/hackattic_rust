1//! API that does not (yet) follow semver.
2//!
3//! All public types under `unversioned` are available to use, but are not considered final
4//! API in the semver sense. Breaking changes to anything under the module `unversioned`,
5//! like `Transport` or `Resolver` will NOT be reflected in a major version bump of the
6//! `ureq` crate. We do however commit to only make such changes in *minor* version bumps,
7//! not patch.
8//!
9//! In time, we will move these types out of `unversioned` and solidify the API. There
10//! is no set timeline for this.
11
